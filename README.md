# Student Management System (CRUD)

## Description
This project is a simple web-based Student Management System developed using PHP, MySQL, HTML, and CSS. It demonstrates basic CRUD (Create, Read, Update, Delete) operations.

## Features
- Add new students
- View list of students
- Edit student details
- Delete student records
- Clean and modern UI design

## Technologies Used
- PHP
- MySQL
- HTML
- CSS

## Purpose
This project was created for academic purposes to demonstrate database integration and CRUD functionality in web development.
